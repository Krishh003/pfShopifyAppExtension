CSV format & available options

Download the template, fill one coupon per row, then drag the file in. The header row is required; columns are matched by name so their order does not matter. Each row is validated in the preview before import — invalid rows are flagged and skipped.

Code required
The code customers type at checkout. Saved in uppercase. e.g. PRISTINE20
Title required
Internal name shown in the admin coupon list.
Discount Type required
Percentage (or Percent) or Amount (or Fixed / Fixed Amount). Any other value rejects the row.
Value required
A positive number. Percent off for Percentage, money off for Amount.
Starts At optional
ISO date, e.g. 2026-12-31T23:59:59Z. Blank = starts immediately.
Ends At optional
ISO date. Blank = never expires.
Usage Limit optional
Positive whole number of total redemptions. Blank = unlimited.
Currency optional
3-letter code, defaults to INR. Only affects Amount discounts.
Status optional
Inactive, Disabled or False = inactive. Blank or anything else = active.

Auto-Add Cart Items

Configure which sample / reward variant gets auto-added at each subtotal tier. Saved to the Shopify shop metafield pristine.preorder_cart_config.

How tiers work & available options

Each tier auto-adds one variant to the cart when the cart subtotal falls inside its range. Add a row per tier, then click Save all tiers to publish — nothing goes live until you save.

Min subtotal required
Lowest subtotal (inclusive) that activates this tier. Use 0 to start from an empty cart.
Max subtotal optional
Highest subtotal (inclusive). Leave blank for "no upper limit".
Variant ID required
Numeric Shopify variant ID of the item to add. Must be greater than 0.
Qty required
Whole number, at least 1. Defaults to 1.
Label optional
Friendly name for your own reference. Omitted if left blank.

Overlap rule: a tier matches when subtotal ≥ min and (max is blank or subtotal ≤ max). If several tiers match, the most specific one wins — highest min first, then the narrowest max range.

What you cannot do: only one reward variant per tier (no multiple variants at the same tier), matching is by subtotal only (not item count or SKU), and edits take effect only after Save all tiers.
